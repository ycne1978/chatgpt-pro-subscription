## 先确认你要充的是哪一档 Pro

OpenAI 目前是两档 Pro：100 美元档（通常叫 Pro 5x）和 200 美元档（Pro 20x）。两档核心能力相同——Pro 模型、Codex、Deep Research、图片生成、Memory、文件上传都在内，主要区别是用量。

几个容易误判的点：

- 5x 和 20x 描述的是相对 Plus 的用量定位，不是模型性能倍数。20x 的回答质量不会比 5x 高四倍。
- 官方明确提示部分模型有独立额度，不同 Pro 档的模型额度可能不一样。某个模型额度用完时它会暂时不可用，等页面显示的时间重置。
- 页面上写 Unlimited 的部分同样受合理使用和防滥用规则约束，不等于可以自动抓取、账号共享或转售。

如果你每天只是聊天、写作、偶尔写点代码，Plus 通常就够用，Pro 多出来的额度会一直躺着。真正需要 Pro 的场景比较集中：整天跑 Codex、多项目并行、长时间深度研究，或者反复撞到 Plus 的额度墙。

**成品号。** 卖家把注册好的账号连同会员一起卖给你。便宜，但账号注册信息、绑定的支付方式都在别人手里，改密、找回、二次出售都由对方决定。搜索结果里出现的"5 元左右 Plus 成品号"就是这个路子。

**共享号 / 拼车。** 多人共用一个账号，隐私先不谈，额度是共用的，撞车时谁都说不清。
